# Hockey GM — AI Logo Generation Prompts

## How to Use

Copy the **Master Style Suffix** and paste it at the end of every individual
prompt below. The suffix keeps all 40 logos visually consistent.

Works with: Midjourney, DALL-E 3, Firefly, Stable Diffusion, Ideogram.

**Ideogram is recommended** — it handles text-free sports badge design the best
and produces the most consistent flat vector results across a batch.

**Save every file using the exact filename listed.** These match the team IDs
in `data/teams.json` and will be loaded by the game as `assets/logos/{id}.png`.

---

## Master Style Suffix

Paste this at the end of every prompt below:

```
-- minor league hockey logo, flat vector badge design, circular emblem shape,
bold simple shapes, slightly cartoonish and goofy, clean thick outlines,
white background, no text, no gradients, no photorealism, no drop shadows,
isolated mascot sports logo style, 2 colors only
```

---

## Tips Before You Generate

- **No text in the prompt** — generate the icon only.
- **If too polished** — add "naive illustration, amateur sports logo, small town
  minor league aesthetic" to the suffix.
- **If too realistic** — add "flat cartoon, simplified shapes, graphic design
  not illustration."
- **Color control** — use the plain English descriptions in each prompt. Use the
  hex codes for any post-processing or CSS work.
- **Aspect ratio** — generate at 1:1 square.
- **Output folder** — save all files to `assets/logos/`
