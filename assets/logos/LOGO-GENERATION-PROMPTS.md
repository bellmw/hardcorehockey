# Hockey GM — Logo Generation Prompts

## HOW TO USE

1. Generate each logo using the prompt below
2. Save the output as a **512×512 PNG with transparent background**
3. Name the file exactly as shown (e.g. `phl_sud.png`) and drop it into this folder (`assets/logos/`)
4. The game picks it up automatically — no code changes needed

---

## GLOBAL STYLE (prepend to every prompt, or set as a style preset)

> 90s minor league hockey logo, vintage screen-printed style, bold flat colors, thick black outlines, slight halftone texture, no gradients, transparent background, centered composition, 512x512px
